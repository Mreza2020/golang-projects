# Task Tracker
It is a CLI program for tracking tasks and managing to-do lists.

This project is a simple command line interface (CLI).

------------------------------

# Features

The program should be run from the command line, accept user actions and inputs as arguments, and save the tasks in a JSON file. The user should be able to:

*  Add, Update, and Delete tasks
*  Mark a task as in progress or done
*  List all tasks
*  List all tasks that are done
*  List all tasks that are not done

------------------------------

# How to use:
`!!! Add, Update, and Delete tasks !!!`

Just enter its name. You can enter the name first or the name can be in uppercase or lowercase.

For other features, simply enter the number opposite it.

To stop the program, it is enough to:

`stop` or `c`
