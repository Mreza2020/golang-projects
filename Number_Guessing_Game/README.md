# Number Guessing Game

This is a simple dice game that can be fun to play.

# Game rules: 

You must add up the dice numbers to reach the game number. For example, if the game number is 20, the sum of your dice numbers must also be 20, neither more nor less.

The game has several different levels.

* Easy
* Normal
* Hard
* Super Hard
* Legendary
* Super Legendary
